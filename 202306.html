2023 六月更新

六月的更新拖到現在（2023-08-01）才寫，對讀者們實在抱歉。六月跟五月相比不怎麼忙碌，只是生活上考了必修的考試、搬了宿舍，設計上做了歐語營的一些貼文圖與講義封面封底，新的社團職位也開始運作。

所以六月我做了什麼？

新社團網站組開始運作

上篇總結提到，我投了一個社團的幹部面試，也如願當上網站長。在與上一屆網站管理員（上屆還沒有網站組）交接完後，發現他們跑的是個 Wordpress 網站，域名 odesignc.com。接下來要學習 Wordpress 的操作，畢竟跟我的個人網站這種手刻 HTML + CSS + 更新腳本的方法可以說是天差地遠。

歐語營製圖

同樣是橫跨五六月的事項。我跟隊友的分法是：我做五月的圖、她做六月的；如果有額外的就均分。所以六月我不用煩惱貼文製圖，但還是做了貼文之外的設計稿——講義封面。

生活雜事

因為沒申請暑宿，六月學期結束後是必要搬宿舍的所有物品回家。跟去年比起來，物品的數量又更多了，跟不同人搬了兩趟才全部搬完。同時，六月學期結束前的例行活動是搖滾樂社的期末展演，好險這次沒接團也沒什麼工作必須做。當然因為是學期末，也考了該考的試。

因為都七月底了才寫六月更新，好像沒什麼寫「未來展望」的必要呢。就留給七月吧。
