使用 Windows 中的 Inkscape 開啟 EPS 檔案

要在 Inkscape 中開啟 EPS 檔案不知道為什麼沒有想像中的簡單，我也不曉得為什麼至今 Inkscape 還未把這個流程直接包入安裝檔裡面。但總之安裝的過程如下：（假設您已安裝 Inkscape）

安裝 Ghostscript

Ghostscript 是 Inkscape 用來讀 PS 與 EPS 檔案的函式庫。

  1. 前往 Ghostscript 官方下載頁面，點選 Ghostscript for Windows (64 bit) 右方的「Ghostscript AGPL Release」連結，下載 Ghostscript 安裝檔。
  2. 安裝下載後的 exe 檔。

複製 Ghostscript 路徑

  1. 開啟檔案總管，前往 C:\Program Files\gs\gs<版本>
  2. 在「lib」上點擊右鍵
  3. 點選「複製路徑」（如果沒有這個選項，按住 Shift 再點擊右鍵）

設定環境變數

  1. 開啟設定 > 系統 > 系統資訊（或是「關於」） > 找到「進階系統設定」
    （也可以按下 Windows 鍵 + R 後，輸入「SystemPropertiesAdvanced」）
  2. 點選「環境變數」
  3. 在使用者變數中找到「Path」
  4. 點擊「編輯」
  5. 點擊「新增」
  6. 貼上在上一 part 複製的路徑
  7. 點擊「確定」
  8. 繼續點擊「確定」讓所有的對話窗關閉

重開 Inkscape

照理來說這時候重開 Inkscape 就能匯入 EPS 檔案了。
