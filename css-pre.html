CSS 中 pre 或其他元素導致破版的解方

我已經看過無數個網站因為程式區塊破版，有時候是因為圖片區塊破版。（破版的意思是，在手機上往右滑會把這個網頁推到左邊，而不只是該區塊。）難道是因為在 Chrome 上不會破版嗎？

解方（CSS）

通常我會這樣解：

body {overflow-x: hidden}
pre {overflow-x: auto}

這樣就只有區塊會在橫向捲動時移動，而且沒有辦法橫向捲動時，捲軸不會被顯示。
